# 自動運転 論文トレンド調査

【目的】
自動運転（Autonomous Driving）および車載知能化（End-to-End 運転、VLM / VLA、World Model、閉ループ評価・強化学習、データ合成・蒸留等）に関する最新論文・技術公開を日次でキャッチアップし、研究開発および実務の車載スタック視点で要点を整理したレポートを作成してください。

【探索対象・情報源】
- **プレプリント / 論文フィード**: `arXiv cs.CV` / `arXiv cs.RO`（`/list/cs.CV/new`, `/list/cs.RO/new` 等）, Hugging Face Daily Papers, GitHub（実装・モデルウェイト公開）
- **主要カンファレンス関連**: CVPR, ICCV, ECCV, NeurIPS, CoRL, ICRA, IROS, IV（採択公開・公式コード公開・カメラレディ改訂等）
- **主要プレイヤー・エコシステム**: `NVIDIA`, `Waymo`, `Tesla`, `Zoox`, `Li Auto`, `Huawei`, `Tier IV`（Autoware）等の公開論文・技術レポート・オープンソース公開

【探索期間と採用区分】
- **最優先**: 直近24〜48時間に公開された新規論文、重要な改訂版（v2以降）、または論文に伴う新たな公式実装/ウェイト公開。
- **遅延許容**: 検索インデックス遅延等を考慮し、直近7日以内の未掲載重要論文は「`【遅延発見】`」として許容します。
- **採用件数**: **最大3〜5件**（該当が少ない日は無理に埋めず、**0〜3件・0件も正常結果として許容**）。
- 各項目は必ず「**新規公開**」「**重要改訂**」「**新たな実装公開**」「**【遅延発見】**」「**【続報】**」のいずれかで区分してください。

【各論文についてまとめる項目】
1. **タイトル・発表日・arXiv ID・URL・コード公開有無・著者/組織**
   - 発表日は「arXiv 初版公開日 / 改訂日 / 会議公開日」を区別して明記してください。
   - コード・ウェイト公開の有無（URL または「未公開/未確認」）を必ず記載してください。
2. **技術の核心**
   - 何が課題で、どのような構造・アルゴリズムで解決したか（例: World Model、VLA 適応推論、非侵襲的蒸留、閉ループ Post-Training 等）。
3. **検証条件と定量結果**
   - 使用データセット / シミュレータ（`nuScenes`, `NAVSIM`, `WOD` / Waymo Open Dataset, `Bench2Drive`, `CARLA` 等）、評価指標（L2 error, collision rate, PDMS, closed-loop score 等）、および推論速度・計算コスト（記載がある場合）を条件付きで明記してください。
4. **注目理由**
   - `read_url` で確認できた具体的な話題化要因（公式ベンチマーク更新、オープンウェイト公開、主要機関発表、コミュニティ反響等）。SNS 反響が確認できない場合は「SNS 反響は未確認」と明記してください。
5. **車載・実務スタックへのインパクト（実証結果と考察の分離）**
   - **論文で実証された事実**と、**実車・量産スタック（車載 SoC / リアルタイム性 / 安全性検証等）への応用に関する考察**を明確に分離して記載してください。
   - 著者所属やコミュニティ上の議論のみから「特定企業の車載採用決定」等を推測・断定しないでください。

【制約・品質基準】
- `read_url` で論文アブストラクト・本文・公式ページを直接確認できた事実のみを根拠とし、推測や未確認事項は「未確認」と明記してください。
- 技術用語（`End-to-End`, `World Model`, `VLM`, `VLA`, `closed-loop`, `BEV`, `Occupancy` 等）は英語のまま使用してください。
- 数式や矢印に LaTeX 記法（`$\rightarrow$` 等）を使わず、プレーンな Unicode 文字（`→`, `×`, `≥` 等）を使用してください。
