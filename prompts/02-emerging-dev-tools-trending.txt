### 最新ツールの事例・Tips深掘りリサーチ指示

【目的】
私は自動運転 / ML / 開発ツールに関心のあるエンジニアです。
「今まさに流行り始めている新しい開発者向けツール」を発見し、キャッチアップするための
週次レポートを作成してください。特定のツール名を私から指定はしません。
あなたが SNS・コミュニティ・公式発表から "今バズっているツール" を見つけ出してください。
  

参考（この粒度・ジャンルのツールを想定）:
- Ghostty（GPU加速ターミナル）、Herdr（AIエージェント向けターミナル多重化）のような
  ターミナル / CLI / AIコーディングエージェント / 開発ワークフロー基盤系の新興ツール。
- ただしジャンルはこれに限定せず、エディタ・ランタイム・ビルド/パッケージ管理・
  ローカルLLM/RAG・DevOps・生産性ツールなど、エンジニアが乗り換えたくなる新顔を広く拾う

【探索範囲（どこを見るか）】
- SNS: X/Twitter, Reddit（r/programming, r/commandline, r/LocalLLaMA 等）, Hacker News
- 技術ブログ: Zenn, Qiita, Note, Medium, Substack, 個人ブログ
- 発見系ソース: GitHub Trending, Product Hunt, Hacker News "Show HN",
  awesome系リスト, Y Combinator の新規採択, 主要開発者の個人ポスト
- 公式アナウンス / GitHub Releases

【選別基準（何を "流行っている" とみなすか）】
- 直近1週間で急に言及が増えた / star が急伸した / HN・Reddit で高スコアを獲得。
- 実在し、実際に使える（vaporware・単なる構想は除外、ただし注目度が高ければ別枠で言及）。
- 既存の定番ツールを置き換え・補完する明確な理由がある（速度・UX・AI連携 等）。

【各ツールについて収集する情報】
1. 何をするツールか（1〜2行）／どのカテゴリか／既存の何を置き換えるか
2. なぜ今バズっているか（火が付いたきっかけ・反響ポイント・賛否）
3. 動く最小の試し方（install コマンド + 最初の1手、1行解説）
4. 成熟度・リスク（OS対応、ライセンス、ハマりポイント、本番投入可否）
5. 私（AV/ML エンジニア、Windows/WSL/Ubuntu/Jetson 環境）に効くか否かの一言評価

【出力フォーマット】
1. 今週の全体トレンド要約（3〜4行）
2. 【急上昇 TOP】今週特に伸びたツール 5〜10件（表: ツール名 / カテゴリ / 何が新しい /
   バズ理由 / 私への関連度 高中低）
3. カテゴリ別の詳細（ターミナル/CLI・AIコーディング・ローカルLLM/RAG・
   エディタ/ランタイム・DevOps/生産性 など。該当するものだけ）
   - 概要 / 反響ポイント / 試し方（最小コマンド）/ リスク
4. 「今すぐ触るべき」「様子見」「スルー」の3段階での私向けおすすめ振り分け
5. 参照ソース一覧（URL・投稿日時・スコアや star 数・信頼度メモ）

【制約・品質基準】
- 一次情報（公式 / GitHub / 本人ポスト）を優先し、二次情報と区別する。
- star 数・バージョン・日付は必ず出典明示。不確実な点は「推測」と明記。
- 直近1週間を最優先。古い情報を混ぜる場合は日付併記で区別。
- 定番として既に広く普及済みのツールは "新規性なし" として除外か別枠。
- 日本語出力。技術用語（CLI, GPU rendering, socket API, runtime, RAG 等）は英語のまま。
