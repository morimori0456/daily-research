# 最新AI（クラウド・Local LLM）動向・活用Tips 日次レポート

【目的】
直近24〜48時間（検索インデックス遅延等を考慮し、直近7日以内の未掲載重要項目は「【遅延発見】」として許容）で公式アナウンス、GitHub/Hugging Face、技術ブログ（Zenn, Qiita, Substack, Note 等）、コミュニティ（Reddit `r/LocalLLaMA`, Hacker News 等）で確認された、以下カテゴリの最新動向・推論Tips・実践知見を差分志向で調査し、日本語の構造化レポートを作成してください。

- **クラウド/クローズド系**: Claude, Claude Code, OpenAI Codex / GPT 系, Google Gemini / Antigravity (`agy`)
- **Local / OSS LLM**: `Qwen3 / Qwen4` 系, `DeepSeek`, `Llama`, `Gemma` 等のオープンウェイトモデル、および推論エコシステム（`llama.cpp`, `vLLM`, `Ollama`, `SGLang`, `TensorRT-LLM`, `LM Studio`, `GGUF` / `AWQ` / `GPTQ` / `FP8` 等の量子化、LoRA/QLoRA）
- **対象ハードウェア / 環境例**: `NVIDIA Jetson AGX Thor`（ARM64 エッジ）、`Intel Arc`、デスクトップ/サーバ GPU、`Ubuntu` / `WSL2`

【スコープ境界（他テーマとの棲み分け）】
- 新興 CLI・開発ツール本体の発掘は別テーマ（02）で扱うため、本レポートでは扱いません。
- Agent / Context / Harness Engineering の研究論文・アーキテクチャ論は別テーマ（04）に譲り、本レポートは**モデルのリリース・更新、推論エンジン（`llama.cpp` / `vLLM` / `Ollama` / `SGLang` / `TRT-LLM`）、量子化/VRAM/KV cache/高速化 Tips、実務導入コマンド**に集中します。

【調査範囲と収集観点】

1. **主要リリース・アップデート（直近24〜48時間最優先）**
   - クローズド系: モデル更新、価格・レート制限改定、context 長、tool calling / MCP / サンドボックス等の機能更新（Claude / Claude Code / Codex / Gemini / Antigravity）。
   - Local/OSS 系: 新モデルウェイト公開、推論エンジン（`llama.cpp`, `vLLM`, `Ollama`, `SGLang`, `TensorRT-LLM`）の新バージョン、新機能（構造化出力、tool calling、speculative decoding、prefix caching、KV cache 量子化等）、対応ハードウェア（`Jetson AGX Thor`, `Intel Arc`, CUDA/Vulkan/SYCL 等）の拡充。

2. **実践的な高速化・運用 Tips と導入コマンド**
   - Local LLM の実用チューニング: 量子化レベル（Q4/Q5/Q8, FP8 等）の選定、context 長・KV cache・VRAM 最適化、推論速度（`tok/s`）改善、OpenAI/Anthropic 互換 API サーバ起動オプション。
   - 実務での業務活用・ハイブリッド運用（API コスト削減、閉域・エッジ常駐、精度/レイテンシの両立、ハマりポイントと回避策）。
   - **コマンド・設定例の明記ルール**: 記載するコマンド・起動オプションは「**原典からの引用**（出典URL付き）」か「**構成上の作成例（未実行）**」かを必ず明記してください。

3. **定量データ・比較の厳格化**
   - 速度（`tok/s`）・VRAM・精度比較は、測定条件（ハードウェア、量子化形式、バッチサイズ、context 長）を必ず併記してください。
   - 条件が異なるベンチマーク同士は安易に同列比較せず、「条件が異なるため直接比較不可」と明記してください。

【採用件数の方針】
- 本日のトピックは**最大3〜5件**に厳選してください。
- 該当が少ない日は無理に件数を埋めず、**0〜3件（該当なし・0件も正常結果として許容）**で構いません。
