### 最新AIの事例・Tips深掘りリサーチ指示

【目的】
直近1週間で SNS（X/Twitter, Reddit）、技術ブログ（Zenn, Qiita, Note, Medium, Substack）、
GitHub/HuggingFace、および公式アナウンスで話題になった、
以下カテゴリの最新動向・活用事例・Tips を網羅的に調査し、構造化したレポートを作成してください。

- **クラウド/クローズド系**: Claude, Claude Code, OpenAI Codex / Code系モデル
- **Local / OSS LLM**: Ollama, vLLM, Qwen（Qwen2.5 / Qwen3 系, Coder 含む）、
  および関連エコシステム（llama.cpp, LM Studio, SGLang, TensorRT-LLM, Text Generation Inference,
  GGUF / AWQ / GPTQ などの量子化、LoRA/QLoRA ファインチューニング）

【調査範囲と収集データ】

1. **主要ニュース・アップデート**
   直近1週間以内に発表・更新された最新機能、モデルのリリース／アップデート内容。
   - クローズド系: 新モデル、価格改定、context長、ツール/エージェント機能、API変更。
   - Local/OSS系: 新モデル公開（Qwen等）、Ollama/vLLM/SGLang等の新バージョン、
     新機能（構造化出力、tool calling、speculative decoding、prefix caching 等）、
     量子化・軽量化手法、対応ハードウェア（GPU/Apple Silicon/Jetson 等）の拡充。

2. **SNS・コミュニティでバズっているTips / プロンプト術・運用術**
   エンジニア・非エンジニア間で反響が大きい具体的テクニック。
   - プロンプト構成、system prompt / エージェント設定のコツ。
   - Local LLM特有の運用Tips: モデル選定、量子化レベル（Q4/Q5/Q8等）の選び方、
     コンテキスト長・KVキャッシュ・VRAM のチューニング、
     推論速度（tok/s）最適化、サーバ起動オプション、OpenAI互換API での置き換え。

3. **具体的な業務活用事例**
   - **開発**: ペアプロ、リファクタリング、テスト生成、コードレビュー自動化、
     大規模コードベースの要約、RAG連携、CLIエージェント運用。
   - **非開発**: 業務自動化、書き捨てツール制作、資料作成、社内文書QA。
   - **Local LLM ならではの事例**: オフライン／閉域環境・機密データでの利用、
     セルフホスト RAG、社内サーバ／エッジ（Jetson等）での常駐運用、
     クラウドAPIからのコスト削減・置き換え事例。

4. **課題と定量的効果**
   - 導入による工数削減・コスト削減データ、精度／速度の定量比較。
   - 直面した課題・ハマりポイントとその回避策。
   - **セキュリティ／データガバナンス**: 機密データ取り扱い、オンプレ vs クラウドの判断軸。
   - **Local LLM の運用課題**: VRAM/ハード要件、量子化による精度劣化、
     スループット・同時実行、モデル更新・バージョン管理、保守コスト。

5. **クローズド系 vs Local/OSS の比較観点**（横断分析）
   コスト、精度／ベンチ、レイテンシ／スループット、プライバシー、
   カスタマイズ性（FT/LoRA）、運用負荷。ユースケース別の使い分け基準。

【出力フォーマット】

1. **全体トレンドの要約**（3〜4行）
2. **主要トピック別詳細**
   - カテゴリ（クローズド系 / Local・OSS系 で区分）
   - 概要と反響ポイント
   - 実際のプロンプト例・導入例・コマンド／起動オプション例
3. **クローズド系 vs Local/OSS 比較表**（コスト・精度・速度・プライバシー・カスタマイズ性・運用負荷）
4. **どの職種・業務で最もインパクトが大きいかの評価**
5. **導入判断のためのユースケース別 推奨マトリクス**
   （例: 機密データ→Local, 最高精度が必要→クローズド 等）
6. **参照ソース一覧**（引用元URL、投稿日時、媒体種別）

## 【制約・注意】
- 直近1週間（本指示実行日を基準）を優先。それ以前の情報は「背景」として明示的に区別。
- 不確実な情報は「推測」と明記し、一次ソース（公式アナウンス／リポジトリ／論文）を優先。
- Local LLM は特にバージョン依存が大きいため、モデル名・バージョン・量子化形式を必ず併記。
- 技術用語（tok/s, KV cache, GGUF, AWQ, LoRA, prefix caching, tool calling 等）は英語のまま使用。
